# Clinical ML Portfolio

Small, self-contained projects on machine learning for medical and biomedical imaging. Each repository covers one technique and one use case, with real metrics against a baseline.

Principles shared by all projects:

- **Reproducibility**: environment managed with [`uv`](https://docs.astral.sh/uv/) and a versioned `uv.lock`, fixed seeds.
- **Traceable data**: public datasets with their licence stated, or synthetic data with ground truth generated by the code. Heavy datasets are not committed; scripts download or regenerate them.
- **Honest evaluation**: quantitative metrics in `results/*.json`, compared with a baseline; data split by patient or subject where the data have one; limitations stated in each README.
- **Quality**: lint with `ruff`, tests with `pytest`, CI on GitHub Actions; a Streamlit app (`app/main.py`) in each project.

## Projects

| Project | Topic | Data | Key result (vs baseline) |
|---|---|---|---|
| [medical-xai-uncertainty](https://github.com/mdegiulio97/medical-xai-uncertainty) | Classification + XAI + uncertainty | Cheng brain MRI, 233 patients, split by patient (CC BY 4.0) + PneumoniaMNIST (CC BY 4.0) | brain: AUROC 0.961 vs 0.881; chest: AUROC 0.963 vs 0.927. At the 0.5 threshold accuracy/F1 are below the baseline (stated in the README) |
| [genai-mri-superres](https://github.com/mdegiulio97/genai-mri-superres) | Image-to-image super-resolution | Real T1w brain MRI (OpenNeuro ds007116, CC0) + BloodMNIST microscopy (CC BY 4.0) | brain, held-out subject: +0.52 dB PSNR, +0.007 SSIM; BloodMNIST: +2.17 dB |
| [pinn-qmri](https://github.com/mdegiulio97/pinn-qmri) | Physics-informed network, T2/T2* relaxometry | Synthetic (ground truth) + real multi-echo brain MRI (OpenNeuro ds007116, CC0) | real brain, held-out-echo validation: NRMSE 0.075 vs 0.100 (least squares) |
| [phasor-flim-explorer](https://github.com/mdegiulio97/phasor-flim-explorer) | Fit-free phasor analysis (FLIM) | Synthetic (ground truth) | unmixing MAE below NNLS fitting at every photon count (e.g. 0.100 vs 0.136 at 300 photons), ~32× faster |
| [rag-radiology-reports](https://github.com/mdegiulio97/rag-radiology-reports) | Local RAG with citations | Synthetic reports | functional check only (author-written queries on a 15-report corpus), not a benchmark |

Reusable template: [**ml-clinical-template**](https://github.com/mdegiulio97/ml-clinical-template) (structure, seeding utilities, CI).

University coursework (archived): [parkinson-voice-classifier](https://github.com/mdegiulio97/parkinson-voice-classifier), [Health-Insurance](https://github.com/mdegiulio97/Health-Insurance).

## How to run a project

```bash
git clone https://github.com/mdegiulio97/<project>.git
cd <project>
uv sync --extra dev
uv run pytest -q                       # tests
uv run python scripts/download_data.py # data (where needed)
uv run python scripts/evaluate.py      # metrics
uv run streamlit run app/main.py       # interactive demo
```

Each project README lists its own scripts (some need a training step first).

## Note

The projects are demonstrations: data are public or synthetic, and none of them is a validated clinical tool. Each dataset is subject to its own licence, stated in the README of the project.
